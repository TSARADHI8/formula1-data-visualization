# 🏎️ Formula 1 Data Visualization Dashboard

An interactive Streamlit dashboard for exploring Formula 1 race data using Python and Plotly. This project provides visual insights into drivers, constructors, race results, circuits, and championship performance through an intuitive web interface.

## 📌 Project Overview

This dashboard was developed as part of a Data Visualization course project. It analyzes historical Formula 1 data and presents interactive visualizations that help users understand trends, driver performance, constructor achievements, and race statistics.

## ✨ Features

- Interactive Streamlit dashboard
- Dynamic filters for data exploration
- Interactive Plotly visualizations
- Driver performance analysis
- Constructor performance analysis
- Circuit analysis
- Race statistics
- Historical Formula 1 insights

## 🛠️ Technologies Used

- Python
- Streamlit
- Plotly
- Pandas
- NumPy

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/TSARADHI8/formula1-data-visualization.git
```

Navigate to the project directory:

```bash
cd formula1-data-visualization
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```
